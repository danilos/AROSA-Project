# Security policy — public project documentation

This repository publishes AROSA's public presentation and receives community feedback. It is **not** the source repository or a supported production release.

Please **do not create public Issues containing security vulnerabilities, credentials, exploit details, unpublished code or sensitive logs**. Until a private security-reporting channel has been configured, refrain from disclosing exploit details here. GitHub repository administrators should enable GitHub Private Vulnerability Reporting if available and publish a verified contact method before inviting sensitive reports.

No security support or vulnerability-response SLA is promised for the current early development preview.
